# sistema-rescate-adopcion-animal
Sistema de control de rescate y adopción animal
## Descripción del proyecto

Sistema académico para gestionar los casos de rescate y adopción animal.

## Funcionalidades previstas
- Registro de casos de rescate.
- Creación de expedientes de animales.
- Notificación a voluntarios.
- Gestión de animales para adopción.

## Arquitectura
El sistema utilizará MVC y los patrones de diseño Singleton, Observer y Factory Method.
